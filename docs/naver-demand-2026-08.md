# 네이버 수요 데이터 판독 (2026-08-25)

출처: 네이버 데이터랩(쇼핑인사이트·검색어트렌드). 값은 **상대지수**다 — 절대 검색수는
검색광고 API 키가 있어야 나온다(`local-agent/naverSearchAd.js` 참조).

## 1. 메탈 vs 가죽 — 시장은 메탈이 4배

패션시계 세분류 클릭량(2025-08 메탈 = 100 기준):

| 월 | 메탈밴드시계 | 가죽밴드시계 | 배수 |
|---|---:|---:|---:|
| 2025-08 | 100.0 | 23.0 | 4.3× |
| 2025-11 | 56.5 | 14.8 | 3.8× |
| 2026-03 | 65.4 | 14.9 | 4.4× |
| 2026-08 | 51.0 | 12.0 | 4.2× |

1년 내내 **4배 격차가 고정**이다. 계절성으로 뒤집히지 않는다.

⚠️ **미니엘 쁘띠 밴드 스왑(화이트로즈골드 메탈 → 화이트블랙 가죽 100개)과 방향이 반대다.**
다만 자사 실측(화이트블랙이 더 팔림·리뷰 220건)은 실제 전환 데이터이고, 위 수치는 시장 전체
클릭량이다. 데이터 위계상 자사 전환이 우선이므로 스왑 자체를 뒤집을 근거는 아니다.
대신 **메탈(화이트로즈골드) 재고를 0으로 만들지 말 것** — 시장 수요의 80%가 그쪽이다.

## 2. 시장이 전년 대비 37% 축소

메탈밴드시계 2025-08 = 100 → 2026-08 = 51.0.
8월이 25일까지만 집계된 점(81% 경과)을 보정해도 약 63 → **YoY -37%**.
가죽도 23.0 → 12.0(보정 14.9)으로 비슷하게 빠졌다.
"우리가 못 판다"가 아니라 **카테고리가 줄고 있다**. 목표 설정 시 반영해야 한다.

## 3. 실수요 연령은 40~50대 (타겟 재검토 필요)

가죽밴드시계 연령별 클릭량(2026-08):

| 연령 | 지수 |
|---|---:|
| 40대 | 79.5 |
| 50대 | 67.7 |
| 30대 | 46.7 |
| 60대 | 26.8 |
| 20대 | 14.2 |
| 10대 | 2.5 |

브랜드 규칙상 폴바이스 타겟은 "30~40대 여성"인데, **50대(67.7)가 30대(46.7)보다 45% 크다.**
메타 광고 연령 타겟이 30~44로 잡혀 있다면 가장 큰 수요층을 통째로 빼고 있는 셈이다.
→ 광고 세트에 45~54 구간을 별도로 열어 A/B로 검증할 것.

## 4. "미니멀·심플" 키워드는 검색 유입이 안 된다

검색어트렌드(여성시계 = 100 기준, 2026-08):

| 키워드군 | 지수 |
|---|---:|
| 여성시계 / 여자시계 / 여성손목시계 | 63.0 |
| 메탈시계 | 8.4 |
| 가죽시계 | 6.6 |
| 폴바이스 / paulvice | 2.1 |
| **미니멀시계 / 심플시계 / 데일리시계** | **0.45** |

미니멀·심플 계열은 여성시계의 **1/140** 수준이다. 상세페이지·광고 카피에서 브랜드 톤으로
쓰는 건 무방하나, **SEO·검색광고 키워드로 잡으면 유입이 없다.** 유입용 키워드는
"여성시계 / 여자시계 / 여성손목시계"다.

## 5. 브랜드 검색은 3월 피크 후 하락

폴바이스 브랜드 검색: 2026-03 4.90 → 08 2.11 (**-57%**).
3~4월에 무엇을 했는지 되짚어 재현할 가치가 있다.

## 재현 방법
현재 이 수치는 세션의 네이버 MCP로 뽑았다. 크론에서 자동 수집하려면 아래 키가 필요하다.

- **절대 검색수**: 검색광고 API — searchad.naver.com → [도구] → [API 사용 관리]
  → `NAVER_AD_CUSTOMER_ID` / `NAVER_AD_API_KEY` / `NAVER_AD_SECRET` → `local-agent/.env`
  → `node local-agent/naverSearchAd.js kw 여성시계`
- **상대지수(데이터랩)**: developers.naver.com 애플리케이션의 Client ID/Secret.
  ⚠️ `.env.local`의 `NAVER_API_HUB_APP_client_*` 는 2026-08-25 기준 오픈API에서
  **401 인증실패**다(검색·데이터랩·쇼핑인사이트 전부). 재확인 필요.
