# 네이버 수요 데이터 판독 (2026-08-25)

출처: 네이버 데이터랩(쇼핑인사이트·검색어트렌드). 값은 **상대지수**다 — 절대 검색수는
검색광고 API 키가 있어야 나온다(`local-agent/naverSearchAd.js` 참조).

## 1. 메탈 vs 가죽 — 여성 기준으론 거의 같다 (초판 정정)

⚠️ **2026-08-25 정정.** 처음엔 "메탈이 가죽의 4배"라고 썼는데 **틀렸다.** 근거로 삼은
쇼핑인사이트 세분류(가죽밴드시계 50004140 / 메탈밴드시계 50004141)는 **성별 구분이 없어
남성시계가 다 섞여 있다**(사장님 지적). 게다가 그 지표는 검색량이 아니라 **카테고리 클릭량**이라
등록 상품 수·노출에 좌우된다 — 수요의 대리지표로 쓰기에 부적절하다.

검색광고 키워드도구의 **절대 월간검색수**로 다시 재면:

| 구분 | 메탈 | 가죽 | 배수 |
|---|---:|---:|---:|
| **여성** (여성/여자 + 메탈/가죽) | **2,455** | **2,260** | **1.09×** |
| 남성 (남성/남자 + 메탈/가죽) | 1,455 | 1,515 | 0.96× |
| 성별 무관 전체 | 7,725 | 6,405 | 1.21× |

**여성 기준으로 메탈과 가죽 수요는 사실상 같다(1.09배).** 남성은 오히려 가죽이 근소하게 많다.
4배는 어디에도 없다.

→ **밴드 스왑(화이트로즈골드 메탈 → 화이트블랙 가죽)을 반대할 근거가 없다.**
   자사 실측(화이트블랙이 더 팔림·리뷰 220건)이 유일하게 유효한 신호이고, 그대로 따르면 된다.
   메탈 재고를 남기라는 조언 자체는 유지할 만하지만("한 SKU를 0으로 비우지 않는다"는
   일반 원칙), "시장 수요의 80%가 메탈"이라는 근거는 **철회한다.**

교훈: 카테고리 클릭량 ≠ 수요. 성별이 갈리는 상품군에서 성별 미분리 지표는 쓰지 말 것.

## 2. 시장이 전년 대비 37% 축소

메탈밴드시계 2025-08 = 100 → 2026-08 = 51.0.
8월이 25일까지만 집계된 점(81% 경과)을 보정해도 약 63 → **YoY -37%**.
가죽도 23.0 → 12.0(보정 14.9)으로 비슷하게 빠졌다.
"우리가 못 판다"가 아니라 **카테고리가 줄고 있다**. 목표 설정 시 반영해야 한다.

## 3. 실수요 연령은 40~50대 (타겟 재검토 필요)

⚠️ 아래도 성별 미분리 카테고리라 재검증했다. **"여성시계" 키워드로 좁혀도 결론은 같다**
(2026-08: 50대 38.4 > 40대 25.4 > 30대 13.0 > 20대 3.4 / 6개월 평균도 40·50대가 압도).
이 항목은 유효하다.

가죽밴드시계 연령별 클릭량(2026-08):

| 연령 | 지수 |
|---|---:|
| 40대 | 79.5 |
| 50대 | 67.7 |
| 30대 | 46.7 |
| 60대 | 26.8 |
| 20대 | 14.2 |
| 10대 | 2.5 |

브랜드 규칙상 폴바이스 타겟은 "30~40대 여성"인데, **50대(67.7)가 30대(46.7)보다 45% 크다.**
메타 광고 연령 타겟이 30~44로 잡혀 있다면 가장 큰 수요층을 통째로 빼고 있는 셈이다.
→ 광고 세트에 45~54 구간을 별도로 열어 A/B로 검증할 것.

## 4. "미니멀·심플" 키워드는 검색 유입이 안 된다

검색어트렌드(여성시계 = 100 기준, 2026-08):

| 키워드군 | 지수 |
|---|---:|
| 여성시계 / 여자시계 / 여성손목시계 | 63.0 |
| 메탈시계 | 8.4 |
| 가죽시계 | 6.6 |
| 폴바이스 / paulvice | 2.1 |
| **미니멀시계 / 심플시계 / 데일리시계** | **0.45** |

미니멀·심플 계열은 여성시계의 **1/140** 수준이다. 상세페이지·광고 카피에서 브랜드 톤으로
쓰는 건 무방하나, **SEO·검색광고 키워드로 잡으면 유입이 없다.** 유입용 키워드는
"여성시계 / 여자시계 / 여성손목시계"다.

## 5. 브랜드 검색은 3월 피크 후 하락

폴바이스 브랜드 검색: 2026-03 4.90 → 08 2.11 (**-57%**).
3~4월에 무엇을 했는지 되짚어 재현할 가치가 있다.
