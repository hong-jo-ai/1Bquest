## 등급 C — 현재 없음 ✅

2026-08-31 대표 확인으로 전 항목이 A 또는 B 로 올라갔다.

**이번에 실제로 틀렸던 값**
- 러그투러그 **43.8mm → 43.2mm**. 0.6mm 오차가 소개자료 PDF·상세페이지·촬영 브리프·
  기획서까지 퍼져 있었고, 대표 실측으로 잡았다. 두께 8.15mm 는 종전 값이 맞았다.

**아직 남은 미검증 1건**
- **문페이즈 주기 "약 29.5일"** — 대표 확인 "달 2개" + RONDA 문페이즈 휠이 통상 59치라는
  일반 지식으로 계산한 값이다. **론다 자료로 확인한 것이 아니다.**
  확인법: 용두로 문페이즈를 한 바퀴 돌려 클릭 수를 센다(59면 확정).
  현재 소개자료 PDF·상세페이지 사양표에 "약" 을 붙여 표기 중.

## 적용 규칙 (앞으로)

1. **등급 C 는 문장에서 뺀다.** "빼면 허전하니 일단 쓴다"가 이번 사고의 원인이다.
2. 새 숫자를 쓸 때는 **이 표에 행을 추가하고 출처를 적은 뒤** 사용한다.
3. `detail-plan.md` 같은 2차 문서를 출처로 인용하지 않는다. 그건 나도 쓴 문서라 순환 참조다.
4. 대표가 말한 값은 등급 B 로 표기하고, 검증 가능하면 A 로 올린다.
5. **소수점이 있는 숫자일수록 의심한다.** 8.15 · 43.8 처럼 정밀해 보이는 값이 오히려
   출처 없이 굳어지기 쉽다. 정밀도가 신뢰도로 착각되기 때문이다.
