## 4. 핵심 운영 규칙 (반드시 준수)

### 4-1. 주문 매칭 원칙
- **이름 + 전화번호** 동시 일치로 매칭 (동명이인 방지)
- 이름만으로 매칭 절대 금지
- 주문 확인 시 **수량(qty) 필드도 반드시 확인** (1개 이상 주문 가능)

### 4-2. 발송 분류 원칙
- **같은 주문번호** 내 상품 → 합배송
- **다른 주문번호** → 같은 고객이라도 별도 분리출고 가능
- 에끌라 골드 주문자: 골드와 **같은 주문번호**의 다른 상품만 4/23 묶음발송
- 다른 주문번호의 상품은 먼저 발송

### 4-3. 배송비 귀책 원칙
- **불량·자사귀책 교환**: 배송비 자사 부담 (허앤쉬 미청구)
- **고객귀책(변심·컬러교환)**: 왕복 6,000원 고객 부담 → 허앤쉬에 청구
- 배송비 청구는 정산서에 가산

### 4-4. 사은품 규칙
- 대상: 대표님이 지정한 명단 (이름+연락처로 매칭)
- 동명이인 주의: 이름만으로 매칭하면 잘못된 사람에게 발송됨
- 에끌라 골드 구매자 중 사은품 대상자는 골드 발송 시 동봉

## 5. 주요 작업 프로세스

### 5-1. 발주서 수신 → 발송 관리 파일 생성

```
입력: 발주서 xlsx
처리:
  1. 발주서 읽기 (pandas)
  2. 에끌라 골드 주문자 분리 → 4/23 탭
  3. 나머지 → 당일/익일 발송 탭
  4. 시계줄 조절도구 구매자 → 별도 탭
  5. 사은품 대상자 → 별도 탭
  6. 동명이인 체크 (같은 이름, 다른 전화번호)
  7. 주문번호 기준 분리출고 대상 체크
출력: 허앤쉬_재발송_발주서.xlsx (날짜별 탭)
```

### 5-2. 운송장 매칭

```
입력: 발주서 + 우체국 운송장 파일
처리:
  1. 이름+연락처로 발주서↔운송장 매칭
  2. 배송상태 확인 (배달완료/접수/운송장출력)
  3. 미발송 건 식별
출력: 허앤쉬_전체주문_운송장.xlsx
```

### 5-3. CS 처리

```
입력: 허앤쉬 CS 접수 메시지
처리:
  1. 고객 정보 조회 (발주서에서 주문번호/주소/연락처)
  2. CS 유형 분류 (반품/교환/환불/빈박스/오발송/불량)
  3. 회수 접수 시 주소 제공
  4. CS 내역 파일 업데이트
  5. 교환/재발송 시 해당 날짜 발송 탭에 추가
  6. 배송비 귀책 판단 및 기록
출력: 허앤쉬_출고관리_리스트.xlsx, 허앤쉬_출고관리_보고서.xlsx
```

### 5-4. 정산서 작성

```
입력: 발주서 + CS 내역 + 배송비 청구 내역
처리:
  1. 전체 판매 집계 (취소 제외)
  2. 상품별 판매수량/반품수량/순수량/단가/매출
  3. 반품 차감
  4. 수수료 30% 계산
  5. 배송비 청구 가산 (고객귀책만)
  6. 최종 정산금액 산출
출력: 허앤쉬_최종정산요청서.xlsx (4탭: 판매내역/반품교환취소/배송비청구/최종정산)
```

### 5-5. 거래명세서 작성

```
입력: 정산서 데이터
처리:
  1. 스크린샷 양식 기반 PDF 생성 (weasyprint)
  2. 공급자 정보, 상품별 판매/반품/TOTAL/단가/공급가액
  3. 한글 금액 표기
출력: 허앤쉬_거래명세서_20260423.pdf
```

## 9. 주요 실수·교훈 (다음 공구 시 반영)

1. **동명이인 체크 필수**: 김효정 010-2600 vs 010-3632 사례. 사은품 잘못 배정됨
2. **주문번호 기준 분류**: 같은 사람이라도 주문번호 다르면 분리출고 가능
3. **수량 필드 확인**: 정하윤 에끌라 골드 수량 2개를 1개로 착각
4. **운송장 데이터 크로스체크**: 이동 처리 전 발송 여부 먼저 확인 (서연주 사례)
5. **에끌라 단가 혼동**: 69,000원이 맞음 (71,000원으로 잘못 기록한 적 있음)
6. **배송비 귀책 구분**: 불량=자사부담, 변심/컬러교환=고객부담
7. **4/23 탭 중복 체크**: 김우정 중복 등록 사례
8. **사은품 동봉 확인**: 최은정 사례 - 분리출고 시 사은품 누락

## 11. 자동화 가능 영역 (Claude Code 구현 우선순위)

### P0: 즉시 자동화
- 발주서 수신 → 날짜별 발송 탭 자동 분류
- 동명이인 자동 탐지 및 알림
- 주문번호 기준 분리출고 대상 자동 분류
- 운송장 매칭 및 미발송 건 알림

### P1: 단기 자동화
- CS 접수 → 자동 분류(반품/교환/수선) + 주소 조회 + CS 파일 업데이트
- 정산서 자동 생성 (CS 반영)
- 거래명세서 PDF 자동 생성

### P2: 중기 자동화
- 카페24 API 연동: 공구 전용 SKU 복제·관리
- 우체국 송장 양식 자동 작성
- 캘린더 연동: CS 팔로업 자동 등록
