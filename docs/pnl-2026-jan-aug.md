## 5. 잠정 손익 (인건비 미확정)

```
매출                        317,686,831
− 채널 수수료               −52,651,814   (16.6%)
− 상품 원가                 −57,692,844   (18.2%)
= 공헌이익                  207,342,173   (65.3%)
− 광고비                    −30,675,545   ( 9.7%)
− 배송·부자재               −13,520,000   ( 4.3%)
− 임대·세무                  −1,930,000
= 인건비 차감 전 이익        161,216,628   (50.7%)
− 인건비·외주(미확정)       −39,500,000?  ← 4번 라벨링 필요
= 추정 영업이익             ≈121,700,000   (38.3%)
```

⚠️ **이 38%는 그대로 믿으면 안 된다.** 빠진 것이 확실한 항목:
- 카드 지출 상세(현대 8.6M + 비자 11.9M = 20.5M)가 위 비용에 대부분 미반영 — 광고·SW·소모품이 여기 섞여 있다
- 대표 급여가 비용으로 안 잡혀 있음(인출로만 나감)
- 감가상각·보험·통신 등 소액 고정비 누락

**보정하면 실질 영업이익률은 25~30% 구간**으로 보는 것이 타당하다.

## 6. 현금이 왜 빡빡한가 — 손익과 현금의 괴리

은행 3계좌 2026년 1~8월: **입금 210,788,901 / 출금 203,280,636 → 순증 7,508,265**

이익이 나는데 현금이 안 남는 이유:
1. **재고 선투자** — 파쇼 34.3M + 나비스트 6.2M = 40.5M이 재고로 잠김 (옥타곤 1,000개는 2년치 물량)
2. **대표 인출** 24.8M
3. **미수금** — 면세점(제드아이티씨) 17.3M 미회수
4. **채무** — 시티워치 27.5M
5. 매출 317M vs 은행 입금 211M → **채널 정산 지연분이 상시 1억 안팎 묶여 있다**

## 7. 개선 레버 — 숫자로

| 레버 | 실행 | 연 효과 |
|---|---|---|
| **① 자사몰 비중 ↑** | 33% → 45% (12%p 이동) | 수수료 절감 **+38M** |
| **② 공구·카카오 수수료 재협상** | 30% → 25% | **+15M** (현 매출 유지 기준) |
| **③ 해리엇 확대** | 공헌이익률 80% 채널. 매출 +50% | **+27M** |
| **④ 광고 연령 재배분** | 35-44(ROAS 2.07) → 45-54(3.14) | 같은 예산 매출 **+15%** |
| **⑤ 면세점 미수금 회수** | 17.3M | 현금(이익 아님) |

①이 압도적이다. **매출을 1억 더 올리는 것보다 자사몰 12%p 이동이 이익에 더 크게 기여한다.**
