## 6. 현금이 왜 빡빡한가 — 손익과 현금의 괴리

은행 3계좌 2026년 1~8월: **입금 210,788,901 / 출금 203,280,636 → 순증 7,508,265**

이익이 나는데 현금이 안 남는 이유:
1. **재고 선투자** — 파쇼 34.3M + 나비스트 6.2M = 40.5M이 재고로 잠김 (옥타곤 1,000개는 2년치 물량)
2. **대표 인출** 24.8M
3. **미수금** — 면세점(제드아이티씨) 17.3M 미회수
4. **채무** — 시티워치 27.5M
5. 매출 317M vs 은행 입금 211M → **채널 정산 지연분이 상시 1억 안팎 묶여 있다**

## 7. 개선 레버 — 숫자로

| 레버 | 실행 | 연 효과 |
|---|---|---|
| **① 자사몰 비중 ↑** | 33% → 45% (12%p 이동) | 수수료 절감 **+38M** |
| **② 공구·카카오 수수료 재협상** | 30% → 25% | **+15M** (현 매출 유지 기준) |
| **③ 해리엇 확대** | 공헌이익률 80% 채널. 매출 +50% | **+27M** |
| **④ 광고 연령 재배분** | 35-44(ROAS 2.07) → 45-54(3.14) | 같은 예산 매출 **+15%** |
| **⑤ 면세점 미수금 회수** | 17.3M | 현금(이익 아님) |

①이 압도적이다. **매출을 1억 더 올리는 것보다 자사몰 12%p 이동이 이익에 더 크게 기여한다.**
