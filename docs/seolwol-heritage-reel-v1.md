# SEOLWOL (설월) 헤리티지 릴스 v1 — 대본 + 비주얼/자막 플랜

> 2026-07-21 작성. 레퍼런스 = "Cartier Santos Story" 릴스(히스토리 스토리텔링 포맷)를 해리엇 톤으로 번안.
> 관련: `docs/harriot-seolwol-launch-prep.md`(영문 카피 원안), `docs/seolwol-package-spec-v1.md`, [[harriot-seolwol-launch]].

## 포맷 규격
- **길이 ~55–60초 · 9:16 세로 · 영어 나레이션(글로벌/영문몰)** + 하단 국문 변형본
- **그레이딩: 차가운 달빛 — 실버블루/B&W**(해리엇 B&W 헤리티지 + 설월 청회색). ⚠️레퍼런스의 웜세피아와 반대로 감 — 설월=겨울/눈=차갑게
- **자막: 워드바이워드 키네틱, 세리프**(해리엇 헤리티지 서체). 발명 비트엔 레퍼런스의 주석기법(도면 라벨) 차용
- **화법: 경건·절제·역사적 무게.** 레퍼런스의 욕설/건방 톤 배제
- **BGM: 희소한 차가운 앰비언트 패드 + 대금/가야금 단음 하나.** 나레이션 전경, 페이오프에서 고조

## 번안 원칙
- **없는 역사 지어내지 않음.** 진짜 문화(雪月·달맞이·한옥 처마) + 진짜 디자인(역방향 문페이즈)로만 신화 구성
- **시계 컷 = 실물 매크로만**(7/27 샘플 후 촬영, AI 창작 금지). 세계(눈·달·한옥·마당)만 AI 생성 허용

## 국문 변형 (harriotkorea 국내몰용, VO 교체)

- 후크: "모든 문페이즈 시계는 같은 이야기를 한다. 달이 차고, 달이 진다. **이 시계는 거부한다.**"
- 세계: "한국의 겨울. 한옥 기와 위로 눈이 쌓이고, 마당 위엔 한겨울의 보름달 — **설월(雪月).** 눈과 달빛이 한 단어에 담긴다."
- 발명: "그래서 뒤집었다. 여기선 **달이 지지 않는다.** 다이얼 한가운데 고정된다. 움직이는 건 달이 아니라, **한옥의 처마다.**"
- 페이오프: "제네바에서 빌려온 기능이 아니라, **손목 위에 머무는 겨울밤.** 설월."

## 제작 순서 & 의존성
1. **지금 착수 가능(세계 컷, AI)**: 눈 내린 한옥 처마·마당 보름달·겨울밤 정적·달맞이 실루엣 — nano-banana/Higgsfield, **차가운 실버블루/B&W 그레이딩 통일**. 가짜 'VOGUE'식 마스트헤드·오탈자 감시.
2. **7/27 샘플 후(실물 컷, 창작금지)**: 다이얼 매크로(고정달+처마 컷아웃 움직임), 처마 노출→가림 시퀀스, 측면 각인, 손목 착용 — **티저 촬영 컷리스트 #1·#2·#3·#4와 동일 촬영에서 확보**.
3. **편집**: 나레이션 녹음(경건한 성우 or 고급 TTS) → 워드바이워드 세리프 자막 싱크 → 켄번스 → 차가운 LUT 통일 → 발명 비트 도면 주석 오버레이.
4. **사운드**: 차가운 패드 + 대금/가야금 단음, 페이오프 고조.

## 배치
- **런칭 D-0 메인 자산**(상세 오픈·광고 동시) 또는 **티저 2탄**(메커니즘 최초 공개)로. 국문=국내 서사, 영문=글로벌 헤리티지.
- ⚠️ 미확정 스펙(무브 'Swiss made' 표기, 3-pass 문디스크 등)은 VO에 사실주장으로 넣지 말 것 — 샘플/인증 확정 후 반영.
