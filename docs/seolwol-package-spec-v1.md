> - **컬러 = Blue Gray** — 해리엇 B&W 헤리티지 원칙의 **의도적 예외**(설월=프리미엄 헤리티지 특별판, 서사가 색을 정당화). 골드/컬러 배제 원칙은 유효하되 설월만 청회색 허용.

> **Design Philosophy**
>
> 패키지는 단순히 시계를 담는 상자가 아니라,
> **'눈 덮인 한옥 지붕 위에 보름달이 걸린 순간'**을
> 사용자가 직접 경험하는 첫 번째 제품이어야 한다.

## 1. 디자인 컨셉

설월의 핵심 디자인은 **눈이 쌓인 한옥 지붕 위에 떠 있는 보름달**이다. 이 장면을 패키지 개봉 과정으로 재현한다.

사용자는
1. 달이 있는 밤하늘(슬리브)을 벗기고
2. 한옥을 마주하며
3. 뚜껑을 열고
4. 설월을 만난다.

즉, 패키지 자체가 하나의 스토리텔링 경험이다.

## 2. 패키지 구조

**타입: 3단 사바리 박스**
- 상부 뚜껑 / 중간 목대 / 하부 박스
- 뚜껑은 위로 완전히 분리되는 방식
- ❌ 자석 여닫이 / 북커버 / 양문형 구조 사용 안 함

## 3. 외부 컬러

**메인 = Blue Gray** (일반적인 블루그레이 아님)
- 컨셉: 겨울, 눈 쌓인 한옥 기와에 햇빛이 비쳤을 때의 차갑고 은은한 청회색
- 무광 / 종이 질감 강조 / 너무 파랗지도 너무 회색도 아닌, 고급스럽고 차분한 톤

## 4. 박스 표면

표면은 최대한 미니멀하게.

**상단**: 한옥 처마선을 **엠보싱(양각) 또는 디보싱(음각)**으로 표현. 절대 일러스트처럼 인쇄하지 않는다. 빛을 받을 때만 은은하게 보이는 수준.

**로고**: HARRIOT — 하단 중앙, 블랙 또는 진한 먹색, 너무 크지 않게.

## 5. 슬리브

**소재**: 프로스트 PET (반투명, 완전 투명 아님)

**디자인**: 설월 문페이즈와 동일한 느낌의 은은한 보름달 인쇄 — 실버 / 그레이 / 펄 인쇄 가능.

**⭐ 가장 중요한 포인트**: 슬리브를 씌웠을 때 **보름달 위치와 박스의 처마선 위치가 정확히 겹쳐져 "지붕 위에 걸린 달"이 완성**된다. 슬리브를 벗기는 순간 밤하늘이 걷히는 경험.

## 6. 내부 컬러

외부보다 따뜻한 톤. 추천: Warm Gray / Ivory / Linen Beige. **❌ 검정 벨벳 사용 금지.** 너무 차갑거나 화려하면 안 된다.

## 7. 내부 구성

- 중앙: 시계
- 오른쪽 또는 하단: 보증서, Story Card
- 깔끔하게 정리되는 구조

## 8. 내부 문구

뚜껑 안쪽에 긴 설명 대신 짧은 문장 하나. 후보:
- "When the full moon rests above a Korean rooftop."
- "Time rests quietly."
- "Remembering Korea."

(최종 문구는 추후 결정 — [[harriot-seolwol-launch]] 영문 카피 톤과 정합)

## 9. 사용 경험 (Unboxing)

① 손에 닿는 종이 질감 → ② 프로스트 슬리브 위의 보름달 → ③ 슬리브 제거 → ④ 처마선 드러남 → ⑤ 뚜껑 분리 → ⑥ 설월 등장.

패키지의 모든 과정이 설월의 디자인 철학을 설명하도록 만든다.

## 10. 제작 방향

국내 제작, 약 500개. 제작 난이도는 높이지 않는다. 복잡한 구조보다 **종이 품질 · 색감 · 엠보싱 · PET 슬리브 · 인쇄 품질에 비용을 집중.**

## 11. 향후 브랜드 확장

이번 설월 패키지는 향후 해리엇 패키지 시스템의 시작.
- **공통 요소**: 3단 사바리 구조 / 동일 규격 / 동일 내부 구조
- **컬렉션마다 변경**: 컬러 / 슬리브 / 스토리 / 엠보싱

패키지는 통일성을 유지하면서 컬렉션마다 하나의 풍경을 담는다.
