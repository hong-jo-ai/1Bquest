# 카카오톡 대화 내보내기 자동화

`../kakaoExport.js` 가 이 폴더의 스크립트를 호출한다. 단독 실행용이 아니다.

| 파일 | 역할 |
|---|---|
| `exportRooms.applescript` | 열린 채팅방 창을 순회하며 CSV 내보내기 (본체) |
| `lclick.js` | CGEvent 좌클릭. 카톡 커스텀 UI 는 AX `click` 을 무시해서 필요하다 |
| `winList.applescript` | 진단용 — 현재 열린 카톡 창 목록 |

## 알아둘 것 (실측 2026-08-28)

- **tmux 안에서는 못 돌린다.** AppleEvent 가 `-1712` 로 죽는다. `ssh localhost` 로
  GUI 세션에 붙어 실행해야 한다 (`kakaoExport.js` 가 그렇게 한다).
- **권한 2종이 sshd 컨텍스트에 필요하다**: 손쉬운 사용, 화면 기록.
  시스템 설정 → 개인정보 보호 및 보안 에서 `/usr/libexec/sshd-keygen-wrapper` 추가.
- **내보낼 방 = 카톡에 창이 열려 있는 방.** 목록을 코드에 박지 않았다 — 방 이름이
  바뀌면 조용히 멈추기 때문이다.
- **저장 패널은 폴더를 기억하지 않는다.** 늘 "다운로드"로 열리고, 래퍼가
  `~/KakaoExports` 로 옮긴다.
- **카톡은 파일을 정상 저장하고도 "내보내기 중 오류" 창을 띄운다.** 성공 판정은
  대화상자가 아니라 파일 생성 여부로 한다.
- **파일명은 NFD 로 온다.** 방 이름을 키로 쓸 때 `.normalize("NFC")` 필수.
- 설정 창은 탭에 따라 높이가 변한다(480~610). 너비 580 으로 판별한다.
