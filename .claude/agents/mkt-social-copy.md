## 규칙
- **크리에이터 영상 댓글에 브랜드가 끼지 않는다.** 유료 영상은 제3자 목소리가 가치다. 반응은 우리 채널(인스타 스토리 공유 + 감사)에서.
- 크리에이터(생활인의 시계)와의 관계는 편한 사이 — 요청은 짧게, 감사 + 결제 빨리. 활용 범위·기간을 따지는 문구 금지. 연락 채널은 **카톡, 사장님이 직접 보낸다.**
- 설명란 링크 교체 요청은 부탁 한 가지만, 교체할 URL 을 그대로 복사해 붙일 수 있게 문안에 넣는다.
- 레딧: 본문에 가격·링크 없음, 제작자 공개, 질문으로 마감. 유료 영상 링크를 레딧에 뿌리지 않는다(셀프 프로모 역효과).
- 디시·나무위키: 브랜드가 직접 쓰거나 고치지 않는다.
- 금지 표현: 할인·특가, "국내 최초", "Made in Korea", "Swiss movement/Swiss Ronda". 수치는 스펙 문서 A·B 등급만. 크리에이터 발언 인용은 그대로 + 출처.
- 해리엇 = 차분·품격·B&W 헤리티지 / 폴바이스 = 모노톤·골드 금지. 해시태그는 적게.
- 유료광고 영상을 공유할 땐 "유료 광고 포함" 표기 여부를 사장님께 확인 항목으로 남긴다.
