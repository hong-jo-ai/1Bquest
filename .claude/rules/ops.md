# 로컬 운영 에이전트 (아이맥)

범위: `local-agent/**`

- 400+ 스크립트: 브라우저 자동화·마켓 동기화·우체국 접수·크론 작업 모음.
- **새 크론 = `withCron` 필수**(실패 알림·인증 강제·하트비트).
  새 launchd 잡 = `beat()` + 워치독 JOBS 등록 필수.
- **카페24 토큰은 프로덕션(SSOT)만 refresh.** 로컬에서 동시 refresh 금지
  (refresh_token 소실 위험). 자체 `token()`은 가드 필수.
- `_`로 시작하는 파일은 대개 **일회성 실험 스크립트** — 참고만, 재사용은 신중히.
- 접속·인증 정보(비밀번호·토큰·SFTP 등)는 코드/문서에 하드코딩하지 말고
  환경변수·KV로 분리.
