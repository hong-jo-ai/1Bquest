# CS 인박스 규칙

범위: `app/api/cs/**`, `lib/cs/**`, `components/Inbox*`

- 전 채널(웹챗·카페24 게시판·식스샵·인스타 등) 통합 인박스.
- 자동 응대는 **불확실하면 발송 금지** → 사장님 텔레그램으로 에스컬레이션,
  방향 회신 받아 다듬은 뒤 미리보기 → 확인 후 발송.
- 취소/변경 **사유가 대화 맥락상 유추되면 되묻지 말 것**(불필요한 질문=마찰).
- 웹챗 답변 알림은 SMS. **글로벌(영문)은 SMS 불가 → 이메일**.
- 고객 문의 시 전 채널 **과거 구매이력**을 컨텍스트로 표시.
- 게시판은 원글뿐 아니라 **운영자↔고객 댓글 전체**가 대화다.
